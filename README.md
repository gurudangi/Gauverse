# GauVerse 🐄

Digital platform for **Shri Ahilyamata Gaushala** — a modern web application for Gaushala management, dairy products, donations, farm visits, and customer engagement.

**Repository:** https://github.com/gurudangi/Gauverse

---

## 📖 Overview

GauVerse is a full-stack web application built to digitally manage a Gaushala. It provides an easy-to-use platform for visitors, customers, and administrators.

| App | Path | Stack | Dev URL |
|------|------|--------|---------|
| API | `apps/api` | Express.js, MongoDB (Mongoose), TypeScript | http://localhost:3000 |
| Web | `apps/web` | React, Vite, TypeScript | http://localhost:5173 |

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/gurudangi/Gauverse.git
```

Move into the project

```bash
cd Gauverse
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```

---

# ⚙️ Environment

Create

```
apps/api/.env
```

Example

```
PORT=3000

MONGODB_URI=your_mongodb_uri
```
