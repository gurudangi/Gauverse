# GauVerse 🐄

A modern web application for Gaushala Management.

## Features

- 🐄 Cow Management
- 💰 Donation System
- 🥛 Dairy Product Store
- 📅 Farm Visit Booking
- 👨‍💼 Admin Dashboard

## Tech Stack

- React
- Vite
- TypeScript
- Express.js
- MongoDB

## Installation

```bash
npm install
npm run dev
```
